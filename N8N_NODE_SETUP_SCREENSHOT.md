## 🔧 למה לא צריך Environment Variables?

במנוי **Starter** של n8n אין גישה ל-Environment Variables, אז פשוט שמים את ה-URL ישירות:

```
❌ לא: ={{ $env.DASHBOARD_URL }}/api/qa-result
✅ כן:  http://localhost:3001/api/qa-result
```

## 🚀 Production (בעתיד)

כשתרצה לעבור ל-production, פשוט:

1. פתח את ה-node "Send to Dashboard"
2. שנה את ה-URL:
   ```
   מ:  http://localhost:3001/api/qa-result
   ל:  https://your-dashboard.onrender.com/api/qa-result
   ```
3. שמור
